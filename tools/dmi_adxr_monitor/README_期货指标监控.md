# 期货技术指标监控工具

基于 akshare 的期货技术指标监控工具，支持 DMI 和 SuperTrend 指标计算和多周期分析。

## 功能特性

- **数据获取**: 使用 akshare 获取期货实时和历史数据
- **DMI 指标**: 计算 +DI, -DI, ADX (方向运动指标)
- **SuperTrend 指标**: 基于 ATR 的趋势跟踪指标，动态支撑/压力位
- **多周期分析**: 支持多个时间周期同时分析
- **周期共振检测**: 自动判断不同周期信号是否一致
- **综合信号**: 结合 SuperTrend 和 DMI 生成交易建议

## 安装依赖

```bash
pip install akshare pandas numpy
```

## 使用方法

### 基本用法

监控热卷主力连续合约（HC0）：

```bash
python3 tools/futures_indicator_monitor.py HC0
```

监控具体合约（如热卷2605合约）：

```bash
python3 tools/futures_indicator_monitor.py HC2605
```

### 支持的合约代码

- **主力连续合约**: HC0 (热卷), RB0 (螺纹钢), CU0 (铜) 等
- **具体合约**: HC2605, HC2606, RB2505 等格式

### 合约代码格式说明

- `HC0` / `RB0` / `CU0`: 主力连续合约（推荐用于交易参考）
- `HC2605`: 2026年5月热卷合约
- `RB2505`: 2025年5月螺纹钢合约

## 指标说明

### SuperTrend 指标

**计算公式**:
```
基本上下带 = HL2 ± (Multiplier × ATR)
HL2 = (最高价 + 最低价) / 2
```

**交易信号**:
- **上升趋势**: 收盘价 > SuperTrend 线（支撑位）
- **下降趋势**: 收盘价 < SuperTrend 线（压力位）

**默认参数**:
- 15分钟: Period=10, Multiplier=3.0
- 60分钟: Period=7, Multiplier=3.0

### DMI 指标

**指标组成**:
- **+DI**: 上升方向指标（反映上涨力度）
- **-DI**: 下降方向指标（反映下跌力度）
- **ADX**: 平均趋向指标（反映趋势强度）

**交易信号**:
- **+DI > -DI**: 看涨信号
- **-DI > +DI**: 看跌信号
- **ADX > 25**: 趋势明确，可交易
- **ADX < 20**: 趋势不明，建议观望

**默认参数**: Period=14

## 综合分析策略

工具会结合 SuperTrend 和 DMI 两个指标生成综合信号：

| SuperTrend | DMI | 综合信号 | 建议 |
|-----------|-----|---------|------|
| 上升 | 看涨 | 【看涨】双重看涨信号 | 考虑做多 |
| 下降 | 看跌 | 【看跌】双重看跌信号 | 考虑做空 |
| 上升 | 看跌 | 【观望】信号冲突 | 等待确认 |
| 下降 | 看涨 | 【观望】信号冲突 | 等待确认 |

## 周期共振检测

当分析多个周期时，工具会检测不同周期的信号是否一致：

- **周期共振**: 不同周期信号一致，可靠性更高
- **周期背离**: 不同周期信号冲突，建议等待一致

## 常见问题

### Q: 获取不到数据怎么办？

A: 可能的原因：
1. 合约代码不正确（尝试使用主力连续合约如 HC0）
2. 网络连接问题
3. akshare 接口变更

### Q: SuperTrend 值为什么是 0？

A: 通常是因为数据不足（需要至少 period 个数据点），增加 `days` 参数获取更多历史数据。

### Q: ADX 值怎么看？

A: ADX 反映趋势强度：
- **< 20**: 无趋势，市场震荡
- **20-25**: 趋势正在形成
- **25-40**: 明显趋势
- **> 40**: 强趋势，可能过度

### Q: 支撑位和压力位如何使用？

A: SuperTrend 线本身就是动态支撑/压力位：
- **上升趋势**: ST 线是支撑位，价格回踩可考虑买入
- **下降趋势**: ST 线是压力位，价格反弹可考虑卖出
