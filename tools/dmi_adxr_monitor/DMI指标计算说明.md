# DMI 指标详细计算说明

## 一、DMI 指标概述

**DMI (Directional Movement Index)** - 方向运动指标，由 J. Welles Wilder 于 1978 年开发，用于判断趋势的方向和强度。

### 组成部分

1. **+DI (Positive Directional Indicator)** - 正方向指标
   - 反映上升趋势的强度

2. **-DI (Negative Directional Indicator)** - 负方向指标
   - 反映下降趋势的强度

3. **ADX (Average Directional Index)** - 平均方向指标
   - 反映趋势的整体强度，不指示方向

---

## 二、计算步骤详解

### 步骤 1: 计算 +DM 和 -DM (Directional Movement)

#### 定义
```
+DM = 今日最高价 - 昨日最高价 (如果 > 0 且 > -DM)
-DI = 昨日最低价 - 今日最低价 (如果 > 0 且 > +DM)
```

#### 规则
- 如果 +DM > -DM，则 -DM = 0
- 如果 -DM > +DM，则 +DM = 0
- 两者都 ≤ 0 时，+DM = 0, -DM = 0

#### 示例计算
| 日期 | 最高价 | 最低价 | +DM | -DM | 说明 |
|------|--------|--------|-----|-----|------|
| 昨日 | 3255.00 | 3250.00 | - | - | - |
| 今日 | 3263.00 | 3256.00 | 0.00 | 3.00 | 下跌3点 |
| 明日 | 3267.00 | 3258.00 | 4.00 | 0.00 | 上涨4点 |

---

### 步骤 2: 计算 TR (True Range)

#### 定义
```
TR = MAX(
  今日最高价 - 今日最低价,
  |今日最高价 - 昨日收盘价|,
  |今日最低价 - 昨日收盘价|
)
```

#### 说明
- 反映当天的真实波动范围
- 考虑了隔夜跳空情况

#### 示例
| 日期 | 最高价 | 最低价 | 昨日收盘 | TR | 计算方式 |
|------|--------|--------|----------|----|----------|
| 今日 | 3263.00 | 3256.00 | 3260.00 | 7.00 | H-L = 7.00 |

---

### 步骤 3: 平滑 +DM, -DM, TR

#### Wilder's Smoothing 公式
```
Smoothed Value = (前一值 × (N-1) + 当前值) / N
```

其中 N = 周期参数（默认 14）

#### 平滑目的
- 减少噪音，使指标更平滑
- 使用指数加权移动平均

#### 示例
```
假设周期 N=14
前一个平滑值 = 100.00
当前原始值 = 50.00

新平滑值 = (100 × 13 + 50) / 14 = 96.43
```

---

### 步骤 4: 计算 +DI 和 -DI

#### 定义
```
+DI = 100 × (+DM 平滑值) / (TR 平滑值)
-DI = 100 × (-DM 平滑值) / (TR 平滑值)
```

#### 范围
- +DI 和 -DI 的范围：0-100
- 数值越大，该方向的力量越强

#### 示例
```
+DM 平滑值 = 32.86
-DM 平滑值 = 12.36
TR 平滑值 = 100.00

+DI = 100 × 32.86 / 100 = 32.86
-DI = 100 × 12.36 / 100 = 12.36
```

---

### 步骤 5: 计算 DX (Directional Movement Index)

#### 定义
```
DX = 100 × |+DI - -DI| / (+DI + -DI)
```

#### 说明
- DX 反映趋势的方向性强度
- 数值越大，趋势越明确
- 范围：0-100

#### 示例
```
+DI = 32.86
-DI = 12.36

DX = 100 × |32.86 - 12.36| / (32.86 + 12.36)
   = 100 × 20.50 / 45.22
   = 45.33
```

---

### 步骤 6: 计算 ADX (Average Directional Index)

#### 定义
ADX 是 DX 的平滑平均值
```
ADX = (前一 ADX × (N-1) + 当前 DX) / N
```

#### 说明
- ADX 反映趋势的整体强度
- 不指示趋势方向，只指示强度
- 范围：0-100

#### ADX 数值解读
| ADX 范围 | 趋势强度 | 说明 |
|----------|----------|------|
| 0-20 | 弱 | 市场震荡，缺乏明确趋势 |
| 20-25 | 中 | 趋势正在形成 |
| 25-40 | 强 | 趋势明确 |
| >40 | 极强 | 趋势非常强劲 |

## 五、DMI 指标的优势与局限

### 优势

✅ **趋势识别**: 能有效识别趋势的方向和强度
✅ **过滤噪音**: 通过 ADX 判断趋势有效性
✅ **适用多种市场**: 期货、外汇、股票等
✅ **参数灵活**: 可根据不同品种调整周期

### 局限

❌ **滞后性**: 基于历史价格，信号有延迟
❌ **震荡市**: 在横盘震荡时容易产生假信号
❌ **参数敏感**: 不同市场需要调整参数
❌ **无止盈**: 仅依靠趋势反转，缺乏止盈机制

## 六、实战建议

### 1. ADX 作为过滤器

```
if ADX < 20:
    # 不交易，市场震荡
    pass
elif ADX >= 25:
    # 趋势明确，跟随趋势
    if +DI > -DI:
        # 做多
    else:
        # 做空
```

### 2. 结合其他指标

- **趋势确认**: 结合 MA、MACD 等指标
- **支撑阻力**: 结合关键价位
- **成交量**: 用成交量确认突破

### 3. 参数优化建议

| 品种类型 | 推荐周期 | 说明 |
|----------|----------|------|
| 高波动品种 | 7-10 | 更敏感，捕捉快速变化 |
| 中波动品种 | 14 | 标准参数，平衡性好 |
| 低波动品种 | 20-25 | 更稳健，减少假信号 |
