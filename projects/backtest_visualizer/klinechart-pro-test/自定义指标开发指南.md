# K线图自定义技术指标开发指南

## 概述

KlineCharts 支持通过 `klinecharts.registerIndicator()` API 创建自定义技术指标。自定义指标创建后可以像内置指标一样使用。

## 基本结构

```javascript
klinecharts.registerIndicator({
  name: '指标名称',
  shortName: '简称',
  precision: 4,              // 精度
  calcParams: [],            // 计算参数
  shouldOhlc: true,          // 是否需要OHLC数据
  figures: [                 // 图形配置
    {
      key: 'value',          // 数据键名
      title: '显示名: ',
      type: 'line'           // 图形类型
    }
  ],
  calc: (dataList, indicator) => {
    // 计算逻辑
    return results;
  }
});
```

## 关键属性说明

### 1. 基本信息
| 属性 | 类型 | 说明 |
|------|------|------|
| `name` | string | 指标唯一标识名 |
| `shortName` | string | 显示名称 |
| `precision` | number | 小数位数，默认4 |
| `calcParams` | array | 计算参数数组，如 [5, 10, 20] |
| `shouldOhlc` | boolean | 是否需要开盘价、最高价、最低价、收盘价 |
| `shouldFormatBigNumber` | boolean | 是否格式化大数值（100K格式） |

### 2. figures 图形配置
定义如何绘制计算结果：

```javascript
figures: [
  {
    key: 'ma5',              // 对应calc返回数据中的键名
    title: 'MA5: ',          // tooltip显示标题
    type: 'line',            // 类型: line(线) | bar(柱) | rect(矩形)
    styles: {                // 自定义样式
      color: '#FF0000'
    }
  }
]
```

### 3. calc 计算函数
核心计算逻辑，接收K线数据返回指标值：

```javascript
calc: (dataList, indicator) => {
  // dataList: K线数据数组
  // indicator: 指标实例，包含calcParams等配置
  return [
    { ma5: 100.5, ma10: 98.3 },  // 每条K线对应一个对象
    { ma5: 101.2, ma10: 99.1 },
    // ... 数组长度必须与dataList一致
  ];
}
```

### 4. regenerateFigures (可选)
当计算参数变化时动态重新生成figures配置：

```javascript
regenerateFigures: (params) => {
  return params.map((p, i) => ({
    key: `ma${i + 1}`,
    title: `MA${p}: `,
    type: 'line'
  }));
}
```

## 完整示例

### 示例1: 简单移动平均线 (MA)

```javascript
klinecharts.registerIndicator({
  name: 'MA',
  shortName: 'MA',
  calcParams: [5, 10, 20, 30],
  figures: [
    { key: 'ma1', title: 'MA5: ', type: 'line' },
    { key: 'ma2', title: 'MA10: ', type: 'line' },
    { key: 'ma3', title: 'MA20: ', type: 'line' },
    { key: 'ma4', title: 'MA30: ', type: 'line' }
  ],
  regenerateFigures: (params) => {
    return params.map((p, i) => ({
      key: `ma${i + 1}`,
      title: `MA${p}: `,
      type: 'line'
    }));
  },
  calc: (dataList, { calcParams, figures }) => {
    const results = [];
    const sums = calcParams.map(() => 0);

    dataList.forEach((kLineData, i) => {
      const result = {};
      const close = kLineData.close;

      calcParams.forEach((param, j) => {
        sums[j] += close;
        if (i >= param - 1) {
          result[figures[j].key] = sums[j] / param;
          sums[j] -= dataList[i - (param - 1)].close;
        }
      });
      results.push(result);
    });

    return results;
  }
});
```

### 示例2: VWAP (成交量加权平均价)

```javascript
klinecharts.registerIndicator({
  name: 'VWAP',
  shortName: 'VWAP',
  precision: 4,
  calcParams: [5, 10, 40, 60],  // 支持多周期
  shouldOhlc: true,
  figures: [
    { key: 'vwap5', title: 'VWAP5: ', type: 'line' },
    { key: 'vwap10', title: 'VWAP10: ', type: 'line' },
    { key: 'vwap40', title: 'VWAP40: ', type: 'line' },
    { key: 'vwap60', title: 'VWAP60: ', type: 'line' }
  ],
  regenerateFigures: (params) => {
    return params.map((param) => ({
      key: `vwap${param}`,
      title: `VWAP${param}: `,
      type: 'line'
    }));
  },
  calc: (dataList, { calcParams, figures }) => {
    const results = [];
    const buffers = calcParams.map(() => ({
      cumVolumePrice: 0,
      cumVolume: 0,
      queue: []
    }));

    dataList.forEach((kLineData, i) => {
      const result = {};
      const typicalPrice = (kLineData.high + kLineData.low + kLineData.close) / 3;
      const volume = kLineData.volume || 0;

      calcParams.forEach((param, j) => {
        const buffer = buffers[j];
        buffer.queue.push({ typicalPrice, volume });
        buffer.cumVolumePrice += typicalPrice * volume;
        buffer.cumVolume += volume;

        if (buffer.queue.length > param) {
          const removed = buffer.queue.shift();
          buffer.cumVolumePrice -= removed.typicalPrice * removed.volume;
          buffer.cumVolume -= removed.volume;
        }

        if (buffer.cumVolume > 0) {
          result[figures[j].key] = buffer.cumVolumePrice / buffer.cumVolume;
        }
      });

      results.push(result);
    });

    return results;
  }
});
```

## 使用自定义指标

### 1. 注册指标
在图表初始化前注册：

```javascript
klinecharts.registerIndicator({ /* 指标配置 */ });
```

### 2. 创建指标
```javascript
const chart = klinecharts.init('chart');

// 创建到主图
chart.createIndicator('VWAP', true, { id: 'candle_pane' });

// 创建到副图
chart.createIndicator('VOL', false, { height: 80 });
```

### 3. 移除指标
```javascript
chart.removeIndicator('MA');
```

## 注意事项

1. **返回数据长度**：`calc` 函数返回的数组长度必须与输入的 `dataList` 长度一致
2. **空值处理**：某些K线位置可能无法计算（如MA前期），返回空对象 `{}`
3. **键名匹配**：返回对象的键名必须与 `figures` 中的 `key` 一致
4. **动态参数**：使用 `regenerateFigures` 支持参数变化时的动态调整
5. **性能优化**：对于大量数据，避免在 `calc` 中进行重复计算

## 常用图形类型

| 类型 | 说明 | 使用场景 |
|------|------|----------|
| `line` | 折线 | MA、VWAP等 |
| `bar` | 柱状图 | MACD、RSI等 |
| `rect` | 矩形 | 布林带等区间 |
| `circle` | 圆点 | 标记关键点 |
