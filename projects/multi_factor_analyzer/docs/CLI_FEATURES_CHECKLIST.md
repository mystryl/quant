# CLI 命令行接口功能清单

## ✅ 已实现功能

### 1. 核心命令 (4/4)

- ✅ **analyze** - 单因子分析
  - 支持因子表达式和已注册因子
  - 支持多种策略（bull, bear, long_short, volatility, all）
  - 支持自定义参数（quantile, top_pct）
  - 支持输出到文件（JSON, CSV）
  - 支持禁用缓存
  - 支持详细输出模式

- ✅ **batch** - 批量因子分析
  - 支持从 YAML 配置文件读取因子定义
  - 支持批量分析多个因子
  - 支持并行处理（--parallel）
  - 自动生成汇总报告
  - 支持输出到指定目录

- ✅ **report** - 生成分析报告
  - 支持 HTML 格式（美观的交互式报告）
  - 支持 JSON 格式（机器可读）
  - 支持 PDF 格式（通过 HTML 转换）
  - 支持自定义报告标题
  - 支持从单个文件或目录读取数据

- ✅ **validate** - 验证因子表达式
  - 检测未来函数
  - 语法错误检查
  - 支持详细模式（--verbose）
  - 提取字段信息

### 5. 命令行选项 (8/8)

- ✅ **全局选项**
  - --version: 显示版本信息
  - --verbose, -v: 详细输出
  - --help: 帮助信息

- ✅ **analyze 选项**
  - --factor, -f: 因子名称或表达式（必需）
  - --instruments, -i: 股票代码或文件（必需）
  - --start, -s: 开始日期（必需）
  -- --end, -e: 结束日期（必需）
  - --output, -o: 输出文件路径
  - --quantile, -q: 多空分组分位数
  - --top-pct: 选股比例
  - --strategy: 策略类型
  - --no-cache: 禁用缓存
  - --verbose, -v: 详细输出

- ✅ **batch 选项**
  - --config, -c: 配置文件路径（必需）
  - --output, -o: 输出目录路径
  - --parallel, -p: 并行任务数
  - --verbose, -v: 详细输出

- ✅ **report 选项**
  - --input, -i: 输入目录或文件（必需）
  - --output, -o: 输出文件路径（必需）
  - --format, -f: 报告格式（html/pdf/json）
  - --title, -t: 报告标题

- ✅ **validate 选项**
  - EXPRESSION: 因子表达式（必需）
  - --verbose, -v: 详细检查信息
