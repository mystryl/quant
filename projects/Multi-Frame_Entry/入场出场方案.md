下面给你一个可以直接交给 ClaudeCode 重构的趋势型出场模块设计方案。
🎯 目标
替换当前：
ATR 固定止盈 / 固定 R 倍数
为：
结构 + 趋势跟踪 + 分级减仓 的动态出场系统
🧠 核心思想
趋势型出场必须满足：
初始风险固定
盈利后才允许移动止损
出场依据“结构破坏”，不是价格距离
大周期没变，小周期回调不出
🏗 模块结构设计
新文件：
exit/trend_exit.py
包含 4 层控制：
1. 初始止损
2. 保本机制
3. 趋势追踪止损
4. 结构破坏强制退出
一、初始止损（入场时确定）
多单：
stop = 最近 swing low
空单：
stop = 最近 swing high
⚠ 必须在入场那一刻锁定

二、保本机制（Break-even）
只有当：
盈利 >= 1R
才允许：
stop = entry_price
R 定义：
R = entry_price - initial_stop

实现：

三、趋势追踪止损（核心模块）
三种可选方式（可参数切换）：
方案 A：EMA 跟踪（推荐默认）
多单：
stop = max(stop, EMA20 - 0.5 * ATR)
空单：
stop = min(stop, EMA20 + 0.5 * ATR)
特点：
不会太紧
自动适应波动
方案 B：结构低点追踪
每当出现新的：
Higher Low
更新止损：
stop = 新 HL
这和你 MSB 逻辑高度一致。
方案 C：Chandelier Exit
多单：
stop = highest_high_N - ATR * k
N=20 常见

五、完整出场决策流程
if 触发结构破坏:
    全部平仓

else:
    更新 break-even
    更新 trailing stop
    if 价格触发 stop:
        平仓
六、增加一个关键优化：最小持仓时间
防止：
入场后一根K线被洗掉
min_hold_bars = 5
在持仓小于该时间前：
不允许触发 trailing stop
但允许触发初始止损

九、回测实验设计

最大回撤
十、预期效果
你会看到：
胜率下降一点
盈亏比显著提升
收益分布出现 fat tail
最大单笔盈利扩大
这才符合趋势策略特征。
十一、最终架构示意
入场（MSB + OB）
      ↓
初始结构止损
      ↓
盈利 > 1R → 保本
      ↓
EMA / 结构 追踪
      ↓
反向结构破坏 → 强制退出
十二、关键理念总结
不要用“距离”定义出场。
用“市场结构是否改变”定义出场。
