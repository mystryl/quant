## 标签生成方法

### binary_label.py: 二分类标签（趋势/震荡）

**目标**: 生成训练标签，区分"有趋势" vs "震荡"

**方法**: 波动率归一化收益

#### 核心思想

使用**波动率归一化**来定义趋势，使不同时期的数据可比：
- 不是用固定的价格变化百分比（如±0.3%）
- 而是用该时期的波动率来归一化收益

#### 计算步骤

```
1. 计算未来收益率（20根K线后）:
   future_return = (future_price - current_price) / current_price

2. 计算滚动波动率（20根K线）:
   volatility_1bar = std(price_pct_change, window=20)
   volatility_20bar = volatility_1bar × sqrt(20)  # 缩放到20根K线

3. 波动率归一化收益:
   normalized_return = future_return / volatility_20bar

4. 生成标签:
   IF |normalized_return| > 1.5σ → label = 1 (有趋势)
   IF |normalized_return| ≤ 1.5σ → label = 0 (震荡)
```

#### 参数配置

```python
BINARY_LABEL_CONFIG = {
    'window': 20,              # 前瞻窗口（根K线）
    'sigma_threshold': 1.5,    # 标准差倍数阈值
}
```

#### 示例计算

**高波动时期** (volatility_20bar = 2%):
```
未来收益 = +3%
normalized_return = 3% / 2% = 1.5σ
|1.5σ| = 1.5 = 1.5 (刚好等于阈值)
标签 = 1 (有趋势)
```

**低波动时期** (volatility_20bar = 0.5%):
```
未来收益 = +0.8%
normalized_return = 0.8% / 0.5% = 1.6σ
|1.6σ| = 1.6 > 1.5 (超过阈值)
标签 = 1 (有趋势)
```

**震荡时期** (volatility_20bar = 1%):
```
未来收益 = +0.5%
normalized_return = 0.5% / 1% = 0.5σ
|0.5σ| = 0.5 < 1.5 (未超过阈值)
标签 = 0 (震荡)
```

#### 优势

1. **跨期可比**: 高波动期和低波动期使用统一标准
2. **自适应**: 根据市场波动率动态调整阈值
3. **统计学依据**: 1.5σ意味着约87%置信度（正态分布）
4. **避免固定阈值问题**: 0.3%在高波动期太小，低波动期太大

#### 防未来函数

- `future_price = price.shift(-20)`: 使用未来20根K线的价格
- 最后20根K线标签为NaN（无法计算未来价格）
- 所有特征已`shift(1)`处理，确保不使用未来信息

#### 标签分布

在热卷数据上：
- 有趋势 (1): 约10-15%
- 震荡 (0): 约85-90%

#### 输出字段

```python
df_result = pd.DataFrame({
    'datetime':           时间戳,
    'close':              收盘价,
    'future_return':      未来收益率,
    'normalized_return':  归一化收益,
    'rolling_volatility': 滚动波动率,
    'trend_label':        二分类标签 (0/1)
})
```

### 方法二: MACD直方图（判断趋势方向）

**目标**: 在确认有趋势后，判断上涨或下跌

**指标**: MACD (Moving Average Convergence Divergence)

**计算方法**:
```python
# MACD线
ema_fast = EMA(close, 12)  # 快线
ema_slow = EMA(close, 26)  # 慢线
macd_line = ema_fast - ema_slow

# Signal线
signal_line = EMA(macd_line, 9)

# Histogram (柱状图)
histogram = macd_line - signal_line
```

**判断规则**:
```
IF histogram > 0  → 上涨趋势
IF histogram ≤ 0 → 下跌趋势
```

**优势**:
- 简单直观
- 计算快速
- 技术分析中广泛使用

**局限**:
- 滞后性（基于历史数据）
- 在震荡市中容易产生假信号
- 准确率约40-50%

### 概率计算规则

#### 1. 震荡状态
当 `P(有趋势) < 0.5` 时:
```
P(震荡) = 1 - P(有趋势)
P(上涨) = 0
P(下跌) = 0
```

#### 2. 上涨状态
当 `P(有趋势) ≥ 0.5` 且 `MACD > 0` 时:
```
P(震荡) = 0
P(上涨) = P(有趋势)
P(下跌) = 0
```

#### 3. 下跌状态
当 `P(有趋势) ≥ 0.5` 且 `MACD ≤ 0` 时:
```
P(震荡) = 0
P(上涨) = 0
P(下跌) = P(有趋势)
```

### 预测示例

**输入** (某时刻的57个特征):
```python
{
    'ema60_slope': 0.002,
    'adx': 25.5,
    'macd_histogram': 0.15,
    'rsi_14': 55.2,
    'atr_ratio': 0.008,
    ...
}
```

**处理流程**:
```
1. 二分类模型预测:
   → P(有趋势) = 0.68

2. 阈值判断:
   → 0.68 ≥ 0.5, 进入方向判断

3. MACD方向判断:
   → histogram = 0.15 > 0
   → 判断为"上涨"

4. 概率输出:
   → P(震荡) = 0
   → P(上涨) = 0.68
   → P(下跌) = 0
```

**最终输出**:
```
信号类型: 上涨
P(震荡): 0.00
P(上涨): 0.68
P(下跌): 0.00
最高概率: 0.68
```

### 预测性能

#### 整体准确率
- **三分类准确率**: 25-30%
  - 主要受限于样本极度不平衡（震荡占60-95%）
  - 趋势信号稀少但准确

#### 分类性能
| 信号类型 | 占比 | 召回率 | 精确率 |
|---------|------|--------|--------|
| 震荡 | 60-95% | ~80% | 高 |
| 上涨 | 2-12% | ~45% | 中 |
| 下跌 | 3-15% | ~45% | 中 |

#### 性能瓶颈
1. **样本不平衡**: 震荡样本远多于趋势样本
2. **方向判断**: MACD准确率仅40-50%
3. **标签阈值**: ±0.3%可能导致部分趋势被标记为震荡

### 方法优势

1. **简单高效**:
   - 无需训练复杂的多分类模型
   - 计算速度快，适合实时预测

2. **复用现有模型**:
   - 使用已验证的二分类模型（AUC=0.54-0.65）
   - 80个季度滚动模型，适应市场变化

3. **易于理解**:
   - 二分类模型判断趋势存在性
   - MACD判断趋势方向
   - 符合技术分析逻辑

4. **可解释性强**:
   - 输出概率值，反映模型置信度
   - MACD直方图可视化和可理解
   - 便于交易者决策参考

#### 适用场景 ✅
- 震荡市场识别（准确率~80%）
