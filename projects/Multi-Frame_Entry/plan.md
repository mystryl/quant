# 🔵 阶段二：趋势状态标签构建

## 🎯 目标

构造三分类标签：

1 = 上涨趋势  
0 = 震荡  
\-1 = 下跌趋势

---

## 标签定义（重要）

以 60min 为中周期：

对每根t时刻的60min K线，计算未来10-20根K的收益率
future_return = (df['close'].shift(-20) - df['close']) / df['close']

按阈值贴标签
df['label'] = 0
df.loc[future_return > 0.003, 'label'] = 1   # 涨
df.loc[future_return < -0.003, 'label'] = -1 # 跌
    

注意：

-   标签必须 shift(-60)
    
-   严格防止未来函数污染

# 📊 实验总结与下一步计划

## 实验回顾（2026-02-20）

### ✅ 已完成工作

**Phase 1: 数据预处理**
- 多周期重采样（1min → 5min/15min/60min/1day）
- 数据质量验证：988,140行，2014-2025

**Phase 2: 趋势标签构建**
- 窗口对比分析（5/10/15/20/30/40根K线）
- 选择20根K线窗口
- 三分类标签：上涨/震荡/下跌

**Phase 3: 特征工程**
- 57个技术指标特征
- 5大类：斜率、强度、结构、波动率、技术指标
- 严格防未来函数：shift(1)

**Phase 4: 模型训练与优化**

尝试1: 三分类模型（绝对阈值0.3%）
- ❌ 严重过拟合，下跌预测失败

尝试2: 二分类模型（绝对阈值0.5%）
- ❌ AUC=0.4055 (< 0.5)

尝试3: 波动率归一化标签（1.5σ）
- ❌ AUC=0.4816，仍低于0.5

尝试4: **Regime过滤 + Walk Forward + 10根K线** ⭐⭐⭐
- ✅ AUC=0.5384 (首次超过0.5！)
- ✅ 测试准确率=58.63% (+54%改善)
- ✅ 震荡召回率=65.65% (+925%改善)

### 🔑 核心发现

1. **市场存在强烈Regime漂移** - AUC逐年波动大（0.50→0.53→0.45→0.66→0.53）
2. **窗口大小至关重要** - 10根K线优于20根K线
3. **Regime过滤有效** - 高波动环境性能提升41%
4. **2025年市场突变** - 高波动比例降至11.8%，趋势策略失效

### 📈 性能对比

| 方法 | 准确率 | AUC-ROC | 震荡召回率 |
|------|--------|---------|-----------|
| 20根K线 + 绝对阈值 | 37.98% | 0.4055 | 6.40% |
| 20根K线 + 波动率归一化 | 41.55% | 0.4816 | 36.49% |
| **10根K线 + Regime过滤** | **58.63%** | **0.5384** | **65.65%** |
