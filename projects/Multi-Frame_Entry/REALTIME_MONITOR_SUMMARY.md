1. **智能数据源选择**

## 扩展性

### 添加新品种

只需在`SYMBOL_CONFIG`中添加配置：

```python
SYMBOL_CONFIG = {
    'RB0': {'full_code': 'HC8888.XSGE', 'name': '螺纹钢', 'model_code': 'HC888'},
    # 添加新品种
    'CU0': {'full_code': 'CU8888.XSGE', 'name': '铜', 'model_code': 'CU888'},
}
```

### 自定义报告格式

修改`format_monitor_report()`函数即可自定义输出格式。
